# Инструкции для ИИ-ассистента

Перед работой прочитай документы в папке `docs_ai/` — это главные документы проекта:

1. `docs_ai/Архитектуры НИР проекта/PROJECT_ARCHITECTURE.md` — архитектура, решения, открытые вопросы, changelog.
2. `docs_ai/Summary литературы/` — структурные описания литературы 1–6.

Затем `README.md` (запуск, структура) и README в подпапках `src/` по необходимости.
Код запускается как модуль из корня: `uv run python -m src.<модуль>`.
