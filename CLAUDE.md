# Инструкции для ИИ-ассистента

Перед работой прочитай документы в папке `docs_ai/` — это главные документы проекта:

1. `docs_ai/Архитектуры НИР проекта/PROJECT_ARCHITECTURE.md` — архитектура, решения, открытые вопросы, changelog.
2. `docs_ai/Summary литературы/` — структурные описания литературы 1–6.

Затем `README.md` (запуск, структура) и README в подпапках `src/` по необходимости.
Код запускается как модуль из корня: `uv run python -m src.<модуль>`.

## Как читать эти документы

- **Ограничения проекта — только в `PROJECT_ARCHITECTURE.md`** (§2 «Ресурсный бюджет» и далее). Базовая цель — ноутбук без GPU; GPU-сервер возможен, но не предполагается. Многократные тяжёлые прогоны на ноутбуке недопустимы, разовые офлайн-вычисления (например, SSL-учитель) допустимы.
- **`Summary литературы` — источник идей и направлений, а не список требований.** Фразы вроде «твоё ограничение "без больших вычислительных мощностей"», «не подходит для твоей задачи» и «метод без нейросети» в этих файлах — артефакт составления обзоров, а не решение проекта. Не отсекай по ним идеи (в том числе SSL и нейросети); проверяй идею по ресурсному бюджету из архитектурного документа.
- README написаны для людей; для работы ассистента главные документы — в `docs_ai/`.
